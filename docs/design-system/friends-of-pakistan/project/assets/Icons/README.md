# Icons

One long arrow in three lengths, plus form glyphs (from the base Solve Study system). There is no icon font or sprite, and no third-party marks.

- `arrow-32.svg` — 32 × 16. Impact tiles, carousel controls, `md` arrow links, buttons with an icon. Ink: black (`#000000`); in code use the `Arrow` component, which draws with `currentColor`.
- `arrow-45.svg` — 45 × 16. The square CTA. Ink: black.
- `arrow-55.svg` — 55 × 16. `lg` arrow links. Ink: black.
- `caret-green.svg` — 12 × 9 triangle, the select caret on light grounds. Ink: `brand-green` (`#006600`).
- `caret-yellow.svg` — the same caret for the green bands. Ink: `primary` (`#FFC700`).
- `chevron-down.svg` — 16 × 16, the admin-form select chevron. Ink: `#6a7282` (a grey outside the token set, as in the source).

Arrows are always decorative next to a text label, 16px tall, and slide 8px right on hover (150ms ease-in).
