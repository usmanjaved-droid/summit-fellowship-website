# Stat

A big light-serif number underlined by a 1px rule, with an uppercase caption beneath — the stats band.

**Provide:** `value` (short: "470+", "$1B+", "92%") and `label` (a clause of 4–10 words, uppercased by CSS).

- Number in `stat` (96px, 72px under 1024px), rule `line-strong`, caption `stat-caption` `space-5` below, max 232px wide.
- Place four in a row inside a green `Section`, optionally over a photo dimmed with `scrim-band`. Colour is inherited, so it also works on white.
