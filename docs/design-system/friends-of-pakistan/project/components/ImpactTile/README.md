# ImpactTile

A square photo tile for an impact area with its name in 24px uppercase and a 32px arrow along the bottom.

**Provide:** `label` (the area: "Climate", "Learning"), `image` and `href`. Lay tiles out 3-up (2-up from 640px, 1-up below) with 8px gaps.

- Bottom-up deep-green `scrim-image` gradient; label inset `space-8`; on hover the gradient drops to 0.2 and the arrow nudges 8px.
- Label and arrow are white on the gradient; keep the photo's busy detail out of the bottom third.
