# Input

A single-line text field in the public-site style: 1px `field-border` (green on light grounds, yellow on the green bands), square, transparent fill, 18px text.

**Provide:** `label` (visible, Semibold, above), `name`, `type`, optional `placeholder`, `hint`, `invalid`, and the usual input props.

- Padding `space-2` × `space-3`; focus adds a 1px `field-border` ring and the 2px `focus` outline. Invalid: `danger-400` border and the hint reads as an error in words.
- Contrast: the border is 6.6:1 on off-white (green) and 8.6:1 on deep green (yellow) — both clear 3:1.
