# ArrowLink

An uppercase Semibold text link followed by the site's long arrow, which slides 8px right on hover.

**Provide:** `children` (2–3 words: "Discover more", "See all challenges", "Get in touch") and `href`. Optional `size`.

- `size="md"`: 18px label, 32px arrow — under a paragraph or carousel.
- `size="lg"`: 24px label, 55px arrow — the closing action of a section or offer on a yellow band.
- Colour is inherited (`ink`): black on off-white, white and yellow; white on the green bands. Never yellow text on a light ground.
- Gap between label and arrow is `space-2`. The arrow is decorative (`aria-hidden`); the label is the accessible name.

Prefer this over a yellow button on yellow bands and for secondary actions.
