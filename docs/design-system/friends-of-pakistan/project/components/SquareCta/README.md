# SquareCta

A 200 × 200 yellow square with an uppercase label top-left and a 45px arrow bottom-right — the homepage's single loudest call-to-action.

**Provide:** `children` (one or two words: "Join us") and `href`. `size="md"` gives the 150px square used from 768px.

- Padding `space-9` (36px), label 24px/30px Semibold uppercase in `on-accent` (black, 13.4:1), arrow nudges 8px on hover.
- Place it beside a headline and paragraph on an off-white or white band, top-aligned with the copy's second paragraph.
- One per page. Under 768px the source lays it out as a full-width yellow bar with label and arrow in a row.
