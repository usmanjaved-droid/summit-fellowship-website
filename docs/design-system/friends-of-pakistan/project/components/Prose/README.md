Long-form rich text: light-serif h1/h2, Semibold sans h3–h6 (h4–h6 uppercase), 18px Book body, lists and green-underlined links; h1–h3 in `ink-brand` green.

**Provide:** `children` (headings, paragraphs, lists, tables) and optional `size="sm"` (14px, used over images).

- h1 72px / h2 55px `serif` Light, 40px above and 24px below; h3 32px, h4 24px uppercase, h5 18px uppercase.
- Paragraph and list spacing `space-4`; list indent `space-8`; items 10px apart; markers `ink-soft`.
- Links: `ink` text, `link` underline (green; yellow on the green bands) 2px offset, underline removed on hover. `strong` is 600.
