# Checkbox

A 20px square checkbox with a 2px `field-border` (green on light grounds, yellow on green) that fills yellow with a black check when on.

**Provide:** `label` (or `children`), `name`, `checked`/`defaultChecked`, `onChange`.

- Label 18px, `space-3` from the box; the whole row is clickable.
- The check is black on the yellow fill (13.4:1).
