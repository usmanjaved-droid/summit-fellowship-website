# Arrow

The site's one icon: a long, thin right arrow with an open chevron head, 16px tall, in three lengths.

**Provide:** optional `length` (32 | 45 | 55; default 45) and `direction` (`right` | `left`). Colour is `currentColor`.

- 32: impact tiles, carousel controls, arrow links (md), buttons with `icon`.
- 45: the square CTA.
- 55: large arrow links (24px labels).

Always decorative (`aria-hidden`) — the text next to it names the action. Nudge it 8px right on hover with a 150ms ease-in.
